# Petty Cash vouchers

Confirmed 3 November 2026: PHP-only, total strictly below PHP 3,000. Department Head approval remains; Finance Associate gives final request approval and creates the printable voucher. No Finance Manager posting, issuance, clearing, tax calculation or deductions apply. The flow ends at the voucher; it does not represent a released payment.

Request details → Petty Cash Voucher → enter reason → Create voucher → Print voucher. All uploaded documents and lines must have been accepted. Each request has one immutable voucher, recording payee, particulars, full approved amount, creator and approval history. PCV-prefixed references are distinct from standard vouchers. Existing General voucher/accounting/payment controls are unchanged.

Legacy Petty Cash requests at or above PHP 3,000 cannot receive a voucher under this policy. No existing transactions are changed or seeded.
